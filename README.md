# Rainfall Prediction Using Machine Learning

## Project Description
This project explores different machine learning algorithms for rainfall prediction using weather data.

## Algorithms Implemented
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Random Forest
- Gaussian Mixture Model (GMM)
- K-Means Clustering
- Decision Tree
- Hidden Markov Model (HMM)
- Hybrid Decision Tree and GMM

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Dataset
The project uses a rainfall dataset containing weather-related information. The dataset is not included in this repository.

Open the uploaded Jupyter Notebook (`.ipynb`) to explore the implementation.
